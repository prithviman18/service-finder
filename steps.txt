================================================================================
LOCAL SERVICE FINDER - STEP-BY-STEP SETUP & RUN GUIDE
================================================================================

1. SYSTEM PREREQUISITES & VERSIONS REQUIRED
--------------------------------------------
- Java Development Kit (JDK): Version 17 or higher (Java 17 / 21 LTS recommended)
  * Download: https://adoptium.net/ (Eclipse Temurin JDK 17)
  * Verify in terminal: `java -version` and `javac -version`

- Apache Maven: Version 3.8+ or 3.9+
  * Download: https://maven.apache.org/download.cgi (or via `brew install maven`)
  * Verify in terminal: `mvn -version`

- Modern Web Browser: Chrome, Edge, Safari, or Firefox.

* NOTE ON NODE.JS:
  Node.js / npm is NOT required!
  The frontend is built using standard Vanilla HTML5, CSS3, and JavaScript (Fetch API).
  The Java backend (Javalin) directly serves both the static frontend and REST APIs.


2. HOW TO INSTALL PREREQUISITES (IF NOT ALREADY INSTALLED)
---------------------------------------------------------
On macOS:
  brew install openjdk@17 maven
  sudo ln -sfn /opt/homebrew/opt/openjdk@17/libexec/openjdk.jdk /Library/Java/JavaVirtualMachines/openjdk-17.jdk

On Windows:
  1. Download Temurin JDK 17 installer (.msi) and install (check "Set JAVA_HOME").
  2. Download Apache Maven binary zip, extract to C:\Program Files\Maven, and add bin to PATH.

On Ubuntu / Debian Linux:
  sudo apt update
  sudo apt install openjdk-17-jdk maven -y


3. HOW TO BUILD & RUN THE PROJECT
---------------------------------
Step 1: Open Terminal / Command Prompt and navigate into the project folder:
  cd service-finder

Step 2: Clean and compile the project into a runnable single JAR:
  mvn clean package

Step 3: Run the compiled application JAR:
  java -jar target/app.jar

Step 4: Open your web browser and visit:
  http://localhost:8080


4. HOW TO RUN WITH DOCKER (ALTERNATIVE METHOD)
----------------------------------------------
If you have Docker Desktop installed, you can build and run with zero Java installation:

  # Build the Docker image
  docker build -t service-finder .

  # Run the Docker container
  docker run -p 8080:8080 service-finder

  # Open http://localhost:8080 in your browser
